# Hermione — brand

## System

| | |
|--|--|
| **Name** | Hermione |
| **Mark** | **Iris** — lens ring + diamond aperture + light point |
| **Wordmark** | `HERMIONE` · ultra-light geometric sans · wide tracking |
| **Field** | `#050505` / `#0A0A0A` |
| **Ink** | `#F5F5F2` (warm off-white, not pure #FFF) |

## Idea

One silent geometry: **glass, focus, a single point of light.**  
No ornament. No slogan on the primary lockup. Deadly quiet.

## Clear space

Keep empty margin ≥ **½ mark diameter** on all sides of the Iris.  
Never stroke the mark thicker than hairline; never fill the diamond.
